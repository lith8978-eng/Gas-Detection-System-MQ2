# نظام ذكي لرصد الغاز وإطلاق الإنذار (Gas Detection System)

مشروع باستخدام لوحة Arduino وحساس الغاز **MQ-2** لرصد تسرب الغازات القابلة للاشتعال أو الدخان، وإطلاق إنذار صوتي/ضوئي فوراً عند تجاوز نسبة الأمان.

## 🛠️ المكونات المستخدمة (Components)
* لوحة Arduino (Uno).
* حساس الغاز MQ-2.
* صفارة إنذار (Buzzer) أو LED أحمر.
* أسلاك توصيل (Jumper wires) ولوحة تجارب (Breadboard).

## ⚙️ طريقة العمل (How it works)
1. يقوم الحساس MQ-2 بقراءة نسبة الغاز في الهواء.
2. يتم تحويل القراءة إلى قيمة رقمية يقرأها الأردوينو.
3. إذا تجاوزت النسبة الحد الآمن، يقوم الأردوينو بتشغيل الإنذار.
4. عند عودة الهواء لطبيعته، يتوقف الإنذار تلقائياً.

## 🔌 طريقة التوصيل (Wiring)
* VCC -> 5V
* GND -> GND
* A0 -> Analog Pin A0
* Buzzer -> Digital Pin 8

## 🚀 كيفية التشغيل (How to run)
1. قم بتحميل كود `Gas_Alarm.ino` وافتحه في برنامج Arduino IDE.
2. تأكد من اختيار نوع اللوحة والمنفذ (Port) الصحيح.
3. قم برفع الكود (Upload) للوحة.
